# MAAR

MAAR's marketing website — a TanStack Start (SSR) app built with React, TypeScript and Tailwind CSS, deployed on Vercel.

## Development

You'll need Node.js 20+.

```sh
git clone <this-repository-url>
cd <repository-name>
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — regenerate `public/sitemap.xml` and build for production
- `npm run preview` — preview the production build locally
- `npm run lint` — run ESLint
- `npm run format` — run Prettier

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
